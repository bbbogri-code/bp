# 혈압 기록장

수축기·이완기 혈압(맥박, 메모 선택)을 측정 날짜·시간과 함께 기록하고, 추이 그래프와 전체 이력을 보여주는 웹페이지입니다.

## 기능
- 혈압 입력 → 날짜·시간과 함께 저장 (지난 측정은 시간을 직접 바꿔 입력)
- 수축기·이완기 추이 그래프 (7일 / 30일 / 90일 / 전체), 고혈압 기준선 140/90 표시
- 전체 이력 표, 대한고혈압학회 기준 분류, 기록 삭제
- 최근 7일·30일 평균
- CSV 복사, JSON 백업 내려받기 / 불러오기

## 데이터 저장
기록은 브라우저의 localStorage에 저장됩니다. 서버로 전송되지 않으며, **그 브라우저에서만** 보입니다.
기기를 바꾸거나 브라우저 데이터를 지우기 전에 "백업 내려받기"로 JSON 파일을 받아 두고, 새 기기에서 "백업 불러오기"로 옮기세요.

## GitHub Pages로 배포
1. 이 저장소에 `index.html`을 올립니다.
2. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/`에서 열립니다.

> 분류는 참고용이며 의학적 진단이 아닙니다.
